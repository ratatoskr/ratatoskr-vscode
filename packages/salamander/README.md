# Salamander for VS Code

Highlighting and snippets for [Salamander](https://salamander.io)'s `.sal` schemas, the files that describe an API once for Zig, C, JavaScript and Lua.

Type a snippet's prefix and press `Tab`:

`struct` `structb` `union` `enum` `bitfield` `error` `field` `trait` `async` `impl` `virtual` `fn` `const`

Writing [Wraith](https://wraith.io) plugins? Install the [Wraith extension](https://marketplace.visualstudio.com/items?itemName=ratatoskr.wraith) instead. It brings this one with it.

Pre-release. Expect breaking changes.
